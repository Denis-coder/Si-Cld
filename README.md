# Учёт СИ — GitHub-версия

Хранилище — репозиторий. Приложение (GitHub Pages) пишет правки через GitHub API одним атомарным коммитом: изменённый лист + запись в историю.
- `data/index.json`, `data/s/N.json` — таблица, **по файлу на лист** (правка = десятки КБ, а не вся таблица)
- `data/history/ГГГГ-ММ.json` — журнал «кто и что менял», по файлу на месяц
- `data/users.json` — люди (только хэши паролей), `data/vault.json` — токен GitHub, зашифрованный **фразой бригады**
- Excel: GitHub Actions собирает `Perechen_SI.xlsx` из вашего `source/original.xlsx` через ~1,5 мин после последней правки
  и кладёт его в ветку `excel` одним перезаписываемым коммитом (репозиторий не пухнет). Скачивание — кнопка «⬇ Excel» в приложении.
- Раз в месяц (1-го, 03:00 UTC) `squash-history` сворачивает историю репозитория в один снимок; старые версии GitHub удаляет сам со временем.

## Новая установка
1. Публичный репозиторий, загрузить всё содержимое (скрытые `.github`, `.nojekyll` — через Add file → Create new file или git).
2. Settings → Pages → `main` / root.
3. Токен: Fine-grained, только этот репозиторий, Contents: **Read and write**.
4. Actions → **seed** → Run workflow (создаст данные из `source/original.xlsx`), затем Actions → **export-xlsx** → Run workflow.
5. Секрет `VAPID_PRIVATE` (Settings → Secrets → Actions) = содержимое `VAPID_PRIVATE_KEY.txt` — для push.
6. Откройте сайт → «Первый запуск»: имя, логин, пароль, токен. Приложение покажет **фразу бригады** — запишите.

## Обновление с предыдущей версии (данные сохраняются)
1. Загрузите в репозиторий всё из архива **кроме папок `data/` и `source/`** (заменить файлы).
2. Actions → **migrate** → Run workflow (переносит таблицу и историю в новый формат, удаляет публичные зашифрованные токены).
3. Откройте сайт под админом: приложение создаст фразу бригады. **Затем создайте на GitHub новый токен**, в «Люди» → «🔑 Фраза / токен» введите его, старый токен удалите (старый лежал в публичной истории).
4. Actions → **export-xlsx** → Run workflow. Остальные устройства: войти заново и один раз ввести фразу.

## Обновление до текущей версии (данные сохраняются)
1. Замените файлы из архива, **кроме папок `data/` и `source/`** (в т.ч. `scripts/*`, `sw.js`, `index.html`, `app.js`, `.github/workflows/*`).
2. Actions → **add-reserve** → Run workflow: добавит недостающие листы (резерв, «Замены июль 2026») и счётчик «всего СИ». Правки не трогает.
3. Обновите страницу в приложении (на iPhone: закрыть приложение и открыть заново).

**Сроки:** манометры, термоманометры и манометрические термометры — 12 мес., биметаллические термометры — 24 мес. (по типу прибора, столбец «Межповерочный интервал» в расчёте не используется). Править: `due()` в `app.js` и `scripts/common.py`.
**Новая таблица Excel:** «Ещё» → «⬆ Загрузить новую таблицу Excel» (только админ). Заменяет ВСЕ данные и оригинал для выгрузки; история остаётся.
**Значок на иконке** показывает число просроченных (рабочие листы, без резерва).

## Обновление до версии с резервом и новым дизайном (данные сохраняются)
1. Замените файлы из архива, **кроме папок `data/` и `source/`**: `index.html`, `app.js`, `scripts/*`, `.github/workflows/*` (появился `add-reserve.yml`).
2. Actions → **add-reserve** → Run workflow: добавит листы «Резерв б|у» и «Резерв (новые)» (327 приборов). Ваши правки и история не трогаются.
3. Откройте сайт, обновите страницу. Резерв виден отдельным блоком и в выпадающем списке листов (группа «Резерв»), в общую статистику он не входит.

## Как устроена безопасность
Личный пароль нужен, чтобы в истории было видно имя. Право писать в репозиторий даёт токен; он открывается фразой бригады
(≈100 бит, подобрать нельзя) и хранится на телефоне. Кто знает фразу — технически может писать от чужого имени.
Ушёл сотрудник: смените токен и фразу («🔑»), у остальных устройств токен перестанет работать и приложение попросит новую фразу.

## Если сжатие истории не сработало
Ошибка про `workflow` при force-push: создайте PAT с правами Contents + Workflows, добавьте как секрет `SQUASH_TOKEN`.
