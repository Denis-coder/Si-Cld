# Учёт СИ — GitHub-версия (без своего сервера)

Хранилище — сам репозиторий. Приложение работает на GitHub Pages и пишет правки в репозиторий через GitHub API.
Файлы данных: `data/db.json` (таблица), `data/history.json` (журнал), `data/users.json` (логины; пароли — только хэши),
`data/subs.json` (подписки на push). Оригинал: `source/original.xlsx` (не меняется). Актуальный Excel: `Perechen_SI.xlsx`
(его после каждой правки пересобирает GitHub Actions за ~1 минуту: оформление, остальные листы и СИ сохраняются).

## Установка (один раз)
1. Создайте **публичный** репозиторий, загрузите в него всё содержимое этой папки (включая `.github` и `.nojekyll`).
   `VAPID_PRIVATE_KEY.txt` в репозиторий НЕ загружайте.
2. Settings → Pages → Source: *Deploy from a branch* → `main` / root. Адрес: `https://ЛОГИН.github.io/РЕПО/`.
3. Токен: GitHub → Settings → Developer settings → Fine-grained tokens → доступ **только к этому репозиторию**,
   Permissions → Contents: **Read and write**. Срок — максимальный.
4. Push: Settings → Secrets and variables → Actions → New secret `VAPID_PRIVATE` = содержимое `VAPID_PRIVATE_KEY.txt`.
5. Откройте сайт: появится «Первый запуск» — введите логин, пароль и токен. Вы — админ. Токен хранится зашифрованным
   вашим паролем; работникам вводить его не нужно — вы создаёте им логины во вкладке «Люди».
6. На телефоне: «Установить приложение» / «На экран Домой» (iPhone: push работает только так, iOS 16.4+), затем 🔔.

## Важно
- Репозиторий публичный: таблица и места установки видны всем. Токен у каждого сотрудника расшифровывается на его устройстве.
  Если уволили сотрудника — удалите его в «Людях» и **замените токен** (создайте новый, заново создайте пользователей).
- GitHub отключает расписания (push) в репозитории без активности 60 дней — правки приложения считаются активностью.
- Пересобрать базу из нового оригинала: загрузите файл в `source/original.xlsx`, запустите Actions → seed (сотрёт текущие правки!).
- Срок годности — функция `due()` в `app.js` и зеркально `scripts/common.py` (править в обоих местах).
